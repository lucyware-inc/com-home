무엇을 만들고 있는가

루씨웨어는 디지털 데이터(DX)를 물리 세계의 실질적 가치(AX)로 환원하는 기술 생태계를 만들고 있습니다.

파편화된 데이터를 연결하고, 사용자와 가장 자연스럽게 상호작용하는 차세대 AI 인프라를 함께 구축할 인재를 기다립니다.

Talent Profile

이런 분을 찾습니다

현실과 디지털을 잇는 가치 창출자

단순 데이터 처리를 넘어, 디지털 지식을 현실 공간의 사용자 경험으로 환원(Analog Transformation)하는 비전에 공감하고 몰입하는 분.

기술적 깊이를 지닌 혁신가

키워드 탐색을 넘어 온톨로지 기반의 의미론적 추론을 고민하고, 시선·행동 중심의 멀티모달 상호작용을 연구하는 엔지니어.

자율적 문제 해결자

능동형 AI 에이전트처럼 복잡한 비즈니스 문제를 스스로 정의하고, 프레임워크 수준에서 유기적인 솔루션을 설계·실행하는 동료.
