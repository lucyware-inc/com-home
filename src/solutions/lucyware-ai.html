현업과 데이터 사이의 거리

데이터는 있는데 묻는 방법이 없습니다. 숫자 하나를 확인하려면 요청서를 쓰고 담당자가 SQL 을 짜고 며칠을 기다립니다. 그 사이 판단은 감으로 내려집니다.

Lucyware.AI 는 그 거리를 없앱니다. 현업이 쓰던 말 그대로 묻고, 어떤 테이블을 어떻게 읽어 나온 숫자인지를 답과 함께 봅니다. 근거가 보이지 않는 답은 검증할 수 없고, 검증할 수 없는 답은 업무에 못 씁니다.

MetaDRAG™ 위에서 돕니다

질의를 만드는 근거는 MetaDRAG™ 가 정리한 메타데이터입니다. 스키마를 모른 채 학습한 모델이 이름을 추측하는 것과, 정리된 구조를 읽고 질의를 조립하는 것은 결과가 다릅니다.

Features

무엇을 하는가

자연어 질의

「지난 분기 거래처별 매출」 처럼 업무의 말로 묻습니다. SQL 을 배우지 않아도 됩니다.

근거가 붙은 답

실행된 질의와 참조한 테이블을 함께 보여줍니다. 답을 믿을지 사람이 판단할 수 있습니다.

권한을 넘지 않는다

계정이 원래 볼 수 있는 범위 안에서만 답합니다. AI 를 통했다고 더 보이면 안 됩니다.

읽기 전용이 기본

질의는 조회로 제한합니다. 데이터를 바꾸는 일은 사람이 결재하는 경로로만 갑니다.

문서와 데이터를 함께

규정·매뉴얼 같은 문서도 같은 창구에서 찾습니다. 답의 출처가 표인지 문서인지 구분해 보여줍니다.

내부 설치 선택

데이터를 밖으로 내보내기 어려운 곳을 위해 사내망 구성과 자체 모델 운영을 지원합니다.
