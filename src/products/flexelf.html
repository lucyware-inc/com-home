무엇인가

flexelf AI Browser 기술 기반의 시선인식 AI 사이니지는 온디바이스(On-device) 하드웨어 패키지, 대화형 멀티모달 AI 알고리즘, 그리고 고성능 서비스 플랫폼의 3대 레이어로 구성된 차세대 인텔리전스 키오스크 시스템입니다.

사용자가 디스플레이를 바라보는 순간 시선과 행동을 정밀하게 감지하고(LMA · LMM), 음성과 객체를 함께 추론해(RNN · R-CNN) 맞춤형 콘텐츠와 서비스를 인터랙티브하게 제공합니다.

판단은 기기 안에서 끝납니다. 센서에서 읽은 것을 서버로 보내고 답을 기다리면 사람이 이미 지나간 뒤에 반응합니다. 온디바이스로 처리하는 이유가 그것입니다.

아래에서 위로 쌓입니다 — 감지하는 것, 해석하는 것, 서비스로 만드는 것.

01

사이니지 패키지

Hardware & Runtime · On-device AI

  • flexelf 전용 웹브라우저 움직임 인식과 웹 서비스를 유기적으로 연동하고 반응형 사용자 경험(UX)을 제공하는 런타임 환경입니다.
  • On-device AI 컴퓨팅 장치 인공지능 GPU 컴퓨터와 센서 모듈을 직접 제어해 초저지연(Low-latency) 데이터 처리를 수행합니다.
  • 하드웨어 · 센서 레이어
    • Vision Sensor (RGB, IR) 정밀 시선 추적과 안면 인식용 고성능 비전 카메라
    • 접근 · 거리 센서 사용자의 물리적 접근과 상호작용 거리 측정
    • 음성 · 초음파 센서 대화형 인터페이스 구축과 객체 감지 지원
    • 통신 · 디스플레이 BLE · 5G 통신 모듈, Full HD 이상 High-bitrate DID

역할 초저지연 센서 데이터 수집과 현장 구동성 확보

02

AI 알고리즘

Intelligence Engine · 대화형 멀티모달

  • LMM 기반 시선 · 안면 인식 거대 멀티모달 모델(LMM)로 시선 위치, 주시 시간, 표정 변화를 실시간 분석합니다.
  • RNN 기반 음성 인식 · 번역 순환 신경망(RNN)으로 다국어 음성 인식과 실시간 대화형 번역을 지원합니다.
  • R-CNN 객체 인식 Region-based CNN 으로 주변 객체와 제품, 사용자 특성을 자동 식별합니다.
  • LMA 기반 움직임 인식 라반 운동 분석(Laban Movement Analysis) 프레임워크로 제스처와 행동 패턴을 정밀 추적합니다.
  • 빅데이터 수집 알고리즘 실시간 시선·행동 데이터를 축적해 AI 모델 재학습 데이터로 쌓습니다.

역할 시선 · 행동 · 음성을 함께 추론해 타깃 맞춤형 UX 제공

03

서비스 플랫폼

Framework & Database

  • Dual S/W Framework 키오스크 하드웨어를 구동하는 On-device S/W Framework 와 AI 알고리즘을 연동·서빙하는 인공지능 서비스 Framework 를 나눠 안정성을 확보합니다.
  • 통합 데이터베이스 체계
    • 운영 DB 장치·센서 정보, 통합 시스템 로그, 시스템 기준정보
    • AI · 데이터 자산 DB 멀티모달 AI Dataset, 마이데이터 수집정보
    • 보안 · 인증 DB FIDO2 기반 생체 2차 인증 정보
  • FIDO2 생체 2차 인증 얼굴을 읽는 장치가 공공장소에 서 있으므로, 인증과 데이터 보안은 선택이 아닙니다.
